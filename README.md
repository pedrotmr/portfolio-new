# Pedro Ramos · Frontend Developer

An interactive portfolio for exploring Pedro’s work, experience, and projects.

![Portfolio preview](public/images/og-preview.png)

**Live site:** [bypedro.com](https://bypedro.com)

## Highlights

- About section and experience timeline
- Selected projects and social links
- Animated interactions and motion effects

## Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS · Framer Motion · Three.js

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
